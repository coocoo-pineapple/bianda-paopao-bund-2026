# 通知 · 0811 · 梦蝶局换了内核和壳，材料要跟着改

发给：**W2（做 PPT / PDF / pptx）** · **W3（做宣传片）**
事实源：`docs/NARRATIVE_v2.md` 第三节（已同步）
产品实况：`node tools/dream-e2e.cjs` 跑一遍就能看到，截图在 `docs/shots-dream/`

---

## 一句话

梦蝶局**不再是「四个 AI 里抓出一个假猎头」**，也**不再开在 PowerPoint 幻灯片里**。
现在它是：**一场 Microsoft Teams 会议，四个 agent 各只看得见一个维度，你派他们互相质问，散会签一份决定书。**

---

## 改了什么（两条，都影响你手上的材料）

### 1. 内核：抓骗子 → 四片叶子 · 买代价

| 旧 | 新 |
|---|---|
| 四个虚构身份，其中一个是假猎头，你押注抓他 | 四个 agent 各只看得见一维：**只算钱 / 只算人 / 只算时机 / 只算最坏** |
| 你是观众，看完押一注 | 你是**调度者**：派 A 去当面质问 B，把 B 那一维看不见的代价撬出来 |
| 揭底 = 逐条回放破绽 | 一格只有他自己说过 = **软**；被别人交叉验过 = **硬** |
| 结果是"押中/没押中" | 结果是**一份签了字的决定书**：四维代价各一条 + 署名谁问出来的 + 哪一格你没买 |
| 成本：无 | 成本：**会议分钟**，三轮共九分钟，八项代价只买得起四项——**取舍就是玩法** |

**新的那句总结（可以直接抄进片子和 PPT）：**

> 只算钱的那个不管你难不难受，只算人的那个不管划不划算——他们说的都对，都是半张脸。
> 你的活儿是让他们互相质问。
> **这不是抓出谁在撒谎，是把你自己那个决定的代价，一项一项摆到桌上。**

**旧的「假猎头」没有全废**：它变成第二个页签「看一局回放」——一场归档的会议录制，
给不想自己出题的人先看一局。四个庄子名（一叶障目 / 匠石 / 老庖 / 井底之蛙）一个字没改，各绑一维。

### 2. 壳：PowerPoint 幻灯片 → Microsoft Teams 会议窗

**所有出现幻灯片界面的梦蝶局镜头/截图都要重拍。**

新界面长这样（`docs/shots-dream/03-round1-hand.png` 是实拍）：

- 标题栏：`梦蝶局 · 四片叶子买代价 | Microsoft Teams`
- 工具条：`● 录制中` `静音` `摄像头` · **第 2/3 轮 · 本轮剩 3 分钟** · **独立调用 6 · 视野隔离 4 路** · `[离开会议]`
- 主舞台：**2×2 参会者宫格**，一格一个 agent，名字下面写着他那一维（「只算钱」「只算人」…），
  正在发言的那格**亮紫边 + 呼吸圈**，每格左上角挂**「真 / 脚」角标**
- 宫格下面：**实时字幕条**（黑底白字），再下面是滚动的会议纪要
- 右侧：**会议聊天栏**，标「私密 · 仅你可见」，军师的私聊在这儿
- 窗底：**「只有你看得见 · 与会者看不到这一栏」**的私密托盘——分钟条 + 四张 agent 手牌 + 亮证据牌
- 底栏：`会议进行中　4 人在线　字幕：中文(简体)　录制将存入 卷宗架`

任务栏多了一个 `T · Teams` 入口。**钉钉条目还在**，军师私聊两边都发。
PowerPoint 窗口也还在，只是里面那页只剩一张「进会议室」的存根卡。

## 你们各自要动的

### W2（PPT / PDF / pptx）

1. 梦蝶局那几页的**配图全部换成 Teams 会议窗截图**（`docs/shots-dream/03-round1-hand.png` / `06-decision.png`）
2. 「四个虚构身份 / 抓假猎头 / 押注」这套说法**整段替换**成上面的四维买代价
3. 调用次数口径：**一局 4–8 次**（旧稿写 4–7 次）。屏幕上有徽章，**数得出来几次就写几次，不许凑整**
4. 「案例卷宗」改叫**决定书**，结构见上表
5. **"多智能体"那一页可以直接用 2×2 宫格截图当主视觉**——不用再画架构图解释，画面自己就是证据

### W3（宣传片）

1. 所有梦蝶局镜头**重录屏**。幻灯片放映的画面一律不能用
2. 新镜头建议顺序（每个都在真界面上跑得出来）：
   - Teams 窗打开，2×2 四个头像亮起，工具条上「独立调用 4 · 视野隔离 4 路」跳数
   - 玩家从底部私密托盘抽一张手牌，点向宫格里另一个人 → 那格边框亮起 → 字幕条打出质问原话
   - 工具条分钟数往下掉 → 「代价买到 3/4 格」
   - 散会：决定书四行，每行行尾一个署名「气泡水/大鱼 · 交叉验过」
3. 旁白「职场的坑，先在游戏里摔一遍，不疼」**继续有效**，不用改
4. 可加的新旁白：**「九分钟，八项代价，你买得起四项。」**
5. 「抓出谁在撒谎」这类词**全部撤掉**——现在的落点是「把代价摆到桌上」
