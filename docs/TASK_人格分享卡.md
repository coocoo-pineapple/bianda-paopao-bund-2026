# 人格分享卡 · 任务清单

## 目标

用户在 Outlook「人才盘点问卷」里测完 16 型职场 MBTI，点一下能存下一张
1024×1536 的分享图，图里带**他自己测出来的真实数据**和一个能扫回站点的二维码。

## 交付物拆成两半

| | 内容 | 谁做 |
|---|---|---|
| 静态 | 16 张纸雕背景图，**画面里零文字** | 本轮生成，入 `public/assets/persona/` |
| 动态 | 浏览器 canvas 画下方信息条 + 二维码，合成后 `toBlob` 下载 | `public/games/persona-card.js`（新文件） |

文字不烤进图：每个人的四维强度、建议工位、天敌型号都不同，烤死就没法个性化。
顺带绕开模型中文排版翻车的风险。

## 边界

- **不碰 `public/games/mbti.js`** —— 未跟踪文件，另一个窗口在做梦蝶局/MBTI。
  本轮只产出 `persona-card.js` 并暴露 `window.personaCard(code, axVals)`，
  接线那一行由那个窗口自己加。
- 不碰 `server/`、不碰 key、不推参赛仓。
- 图片入 `public/assets/persona/`，同时压 webp，png 走
  `public/assets/orig-full/` 那条既有的「原图不入库」规矩。

## Prompt 模板（无字版）

```
微缩纸雕摄影，竖版正方形构图。深靛蓝色撕边纸层层叠叠围成一个办公室洞窟，
{场景}。唯一光源是{光源}，其余全部沉在深蓝阴影中。电影感布光，浅景深，
微缩模型摄影，纸张纤维与撕边质感清晰，全部由纸制成，没有任何真实照片元素。
画面中不要出现任何文字、字母、数字或标识。
```

最后一句是关键：不写死，模型会自己往纸片上刻英文。
