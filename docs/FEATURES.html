1付费墙实体交互 强烈建议三篇 800 字长文是全站最硬的干货，但"付费解锁"只是一句说明。做法：每篇后半段高斯模糊 + 「¥9.9 解锁全文 · 已有 217 人解锁」按钮 → 假支付弹窗 → 模糊消失。评委亲眼看见"内容变成钱"的那个动作，比十行商业模式介绍都硬。小 ~40 行
2蒸馏问答 强烈建议你最早的功能钩子清单里就有它，至今没实现。做法：干货区顶部「本周高频三问」卡——机器人从水面 1,284 次吹气里蒸馏出 3 个问题+答案摘要，第 3 问答案模糊，「¥4.9 看完整蒸馏」。展示"水面的噪音被机器人提炼成可卖的知识"——干货的生产线，不只是干货本身。小 ~50 行
3发起咨询入口（买家视角） 建议现在的邮箱是卖家视角（收单），评委看不到"怎么花钱"。做法：干货区每篇文章作者名旁 +「向他提问 ¥99」按钮 → 跳邮箱生成一封收件人为林默的草稿。买卖闭环补齐，且把干货区和邮箱缝起来（新增一条关联线）。小 ~25 行

5内推赏金流程岗位表说"成功入职双方得赏金"但没数字没流程。做法：岗位表加「赏金」列（¥500-2000），点内推行弹"押上名声担保 · 入职后你和 TA 各得一半"。微 ~15 行
