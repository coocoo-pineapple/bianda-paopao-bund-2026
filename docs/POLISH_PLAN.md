## 验收五测（每个模块过一遍，就是"炼化的 skill"）

1. **三秒测**：截图给同事，三秒内以为是真软件
2. **手贱测**：可见控件点了都有反应——做不了的给幽默拒绝，不许沉默
3. **心疼测**：至少一句让打工人心里一疼的文案；零说明书腔
4. **对账测**：数字/人名/价格与全站一致（599/99/4186/角色班底）
5. **咬合测**：与剧情模式、任务栏、其他窗口的互相引用全部真实可达
