# 变大泡泡 · 定帧图提示词 v2（纸雕定格风）

> 风格基准：用户参考图——**立体纸雕定格动画**（撕边深蓝纸浪、牛皮纸齿轮机械、剪影小人、橙色丝带路径、微缩舞台暖光、蓝底白字纸牌匾）。
> 用法：把「风格前缀 + 该帧描述」整段贴进 **即梦 / 可灵 / 豆包** 等生图产品。中文提示词为主（这类产品中文理解更好），括号内英文可选加。
> 牌匾文字：提示词里让模型留**空白牌匾**，字卡后期压真字，模型写字必坏。

## 风格前缀（每条前面都加）

```
立体纸雕定格动画场景，多层撕边深蓝色纸浪，牛皮纸板做的齿轮和机械装置，
深色卡纸剪影小人（职场衣着），橙色丝带轨道和木珠，微缩舞台式暖色聚光，
浓郁的手工纸质感和景深，画面里预留空白的蓝底纸牌匾（不写字），16:9，无文字无水印
```

## A. 转化线（5 帧）

### A1 · 双档咨询「机器人 99 一单，真人 599 一单，都有人付」
```
一个纸雕职场人和他的纸板机器人分身背靠背坐在两个圆形纸台上，
一队牛皮纸信封沿橙色丝带轨道分成两条岔路飞来：小信封流向机器人，
一只大信封落进真人手里，信封边缘透出金色微光，中央齿轮传动带连接两个纸台
```

### A2 · 技能市场「卖那件你十分钟干完、别人搞三小时的事」+ 补充：可交换、可悬赏
```
纸雕集市场景：三个牛皮纸摊位分别摆着发光的表格公式、一叠幻灯片、一张简历，
剪影小人们沿橙色丝带排队，其中两个小人正在互相交换手里发光的纸卡（技能互换），
集市中央立着一根悬赏柱，柱上钉着几张空白悬赏纸牌，一枚木珠金币挂在最上方
```

### A3 · 蒸馏成机器人「你睡觉的时候，它替你答题，钱走你的账」
```
纸雕蒸馏装置：上层一个趴在办公桌上睡着的剪影小人，金色纸滴顺着纸板玻璃管
往下滴进下层一个小纸板机器人体内，机器人正拿着纸电话接单，
一串木珠硬币沿另一条橙色丝带从机器人流回睡着的人的口袋，齿轮在底座转动
```

### A4 · 转化漏斗「1,284 → 312 → 96 → 14，每个数字都是活人」
```
侧视纸雕漏斗：四层撕边纸浪水池从上到下逐层收窄，成群的剪影小人像鱼一样
顺水往下游，每层人数骤减，最底层只剩十四个小人，每人手里举着一枚木珠金币，
四层池边各立一块空白蓝底纸牌匾，橙色丝带从顶层贯穿到底层
```

### A5 ·（补充）技能悬赏「有人出钱等你会的那一手」
```
纸雕布告栏特写：一面牛皮纸板告示墙钉满空白悬赏纸条，每张纸条下挂着小木珠金币，
一个剪影小人踮脚撕下其中一张，身后三个小人手里举着各自发光的技能纸卡等着揭榜，
橙色丝带从告示墙延伸到画面外
```

## B. 趣味线（3 帧）

### B1 · 伪装本体「跟 2003 年那个气泡屏保一模一样」
```
过肩视角纸雕场景：纸板老板剪影从工位后走过，显示器纸框里飘着几颗
半透明玻璃质感的纸雕泡泡（内藏微小对话气泡剪影），桌面摊着纸板表格，
老板的影子投在隔断上，一束冷光从显示器透出，其余是暖色舞台光
```

### B2 · 梦蝶局「其中一个是假猎头」
```
俯视纸雕牌局：四只彩纸蝴蝶围坐方形纸桌，每只蝴蝶在桌面投下一个
职场人剪影影子，其中一只的影子是狼形，桌面中央一叠空白纸牌，
顶光如赌局审讯灯，深蓝纸浪包围整个牌桌，橙色丝带绕桌一圈
```

### B3 · 菜园毒菜「不标真伪的菜，会烂在你手里」
```
纸雕农田：田垄是放大的纸板表格网格，一个小纸板机器人农夫弯腰收割
发光的纸雕白菜，每颗白菜挂着小纸牌（绿勾/黄问号/灰叉），
篮子里有一颗没挂牌的白菜正在变红腐烂冒纸屑，远处深蓝纸浪起伏
```

## 生成建议

- **推荐工具**：即梦（参考图那种质感的同源产品）/ 可灵 / 豆包。每帧生 4 张选 1
- 若工具支持**参考图**功能：把你手里那三张截图作为风格参考喂进去，一致性会再上一档
- 视频模型（即梦视频/可灵视频）：直接用同一段提示词 + 「镜头缓慢推进，纸雕元件轻微机械运动」
- 免费 API 通道（Pollinations flux）已验证撑不起这个风格的叙事密度，只做占位用：`node tools/genimg.js 帧号`
