## 一、梦蝶局是什么

作品是「变大泡泡」——伪装成 Windows 桌面的**跨公司匿名摸鱼社区**。水面上飘的泡泡是别人说的话，戳破就看到内容。

梦蝶局嵌在桌面的 **PPT 窗口**（`#winPPT` 的 `v-review` 页）里，是评委必看模块。名字出自庄周梦蝶：**你以为在跟人说话，可能在跟一个分身说话；你以为看到的是真相，可能只是别人想让你看到的那一面。**

玩法内核：给你一个职场场景 + 四个角色，让 AI 把这场戏演一遍，你要在台词里认出**谁在撒谎**。演完摊牌，破绽会被存进资讯库，变成下次能用的干货——「玩过的局，不白玩」。

它在产品里的位置：这是**机器人链路的消费端出口**。现有链路已经有三段——

| 段 | 在哪 | 干什么 |
|---|---|---|
| 造 | 机器人工坊 `WORKSHOP_DEFAULT`（app.html:3697） | 用户写四段设定调教自己的分身：`dna` / `framework` / `flow` / `ban` |
| 养 | 机器人菜园 `winFarm`（os.js:877） | 分身放养在社区里活动，隔天回来收 |
| 卖 | 技能市场 `winSkillMart`（os.js:1195） | 本事标价换钱 |

**缺的就是第四段：雇来的机器人到底能干嘛。** 梦蝶局补这一段。

## 二、现状代码地图（app.html，都在内联里）

### 两个模式

- **剧本局**：`DREAM_PLAYS`（:3390），两个 12 句剧本「内推的那位」「表哥的项目」，`liar` 都是 `一叶障目`，撒谎的句子带 `tell` 字段
- **AI 开局**：`AD` 状态机（:3528），`st` 走 `setup → wait → play → done`。引擎 `adEngine()` 打 `POST /api/ask {system, q}` → `{ok, text, model}`。服务端硬上限：system 2000 字符 / q 500 字符 / 回复 1200 字符 / max_tokens 400
- **诚实标注铁则**：真模型成功 → `AD.src='model'` → 标「真实模型生成」；解析失败或断网走 `adScriptGen()` → `AD.src='script'` → 标「脚本模拟 · 未调用模型」。**这个诚实标注不许拿掉**

### 卡牌系统（昨天刚做完，可直接复用）

CSS 在 app.html 约 1623–1760。DOM 契约：

```
.dcast[.deal|.dealt|.shuffling|.hasfocus]
  └ .cardw (perspective)
      └ .idcard[.speaking|.liar|.mybet]  style="--dd:0.16s"

.dspeech      台词气泡，箭头位置由 --ax 控制
.dlog         历史台词折叠滚动区

```

JS 共用件（`dreamRender` 之前，约 :3435）：

- `DWC` — 四色蝶翼常量数组
- `dreamCastHTML(roles, opts)` — `opts = {deal, shuffling, canBet, bet, liar}`，两个模式共用
- `dreamSpeech(nm, role, tx)` / `dreamLogHTML(rows)`
- `dreamAim()` — 用 `getBoundingClientRect` 把气泡箭头对准发言牌，夹在 7–93%
- `dreamStage(deal, speakIdx)` — **必须走这个**

**最容易踩的坑：`innerHTML` 每帧重建 DOM，同帧加 class 不会触发 transition。** 所以 `dreamStage()` 里是 `void d.offsetWidth` 强制回流 → `requestAnimationFrame` → 再加 `.dealt` / `.hasfocus` / `.speaking`。新写的渲染分支也要走这条路，否则动画全哑。

**第二个坑**：`.view{display:none}` 是全局规则，但 `.dwin .view{display:block}`——窗口内所有 view 都是 block 且**不会挂 `.on` 类**。任何 `#winPPT ... .on` 的选择器永远不匹配。

**第三个坑**：`#winPPT .paper2{aspect-ratio:16/9;overflow:auto}`。幻灯片是定比例盒子，牌桌超高就出现内滚动条，很丑。现有高度：待机 243 / 播放 315 / 揭底 362，**一屏内**。加新元素必须重测。

## 四、卡牌玩法怎么设更好（重点，用户问的就是这个）

**现在的问题**：牌只是会翻面的头像卡。全局玩家只点一次（押注），其余时间在看动画。**卡牌感只在视觉，不在玩法。**

### 建议骨架：三轮质询局

玩家不是第五个角色，是**读局的人**。桌上四张身份牌（暗置底牌 = 真实动机），玩家手里有 3–4 张**质询牌**——这才是真正的"卡"。

每轮循环：

```
四人各说一句  →  玩家打出 1 张质询牌指向某人  →  那人被迫补一句（这句更容易露馅）  →  命中则点亮破绽格
```

三轮后摊牌。

### 质询牌（四种）

| 牌 | 效果 | 从哪来 |
|---|---|---|
| 追问 | 逼对方给一个具体数字 / 名字 / 时间 | 平台默认 |
| 翻旧账 | 调出他前面说过的话对质，前后矛盾就点亮 | 平台默认 |
| 亮证据 | 消耗资讯库 `S.lib` 一条干货，直接锤 | 需要库里有存货 |
| 闭麦 | 让某人本轮不发言，看别人怎么补位 | **雇来的机器人才给** |

### 破绽槽

每张角色卡底部三格，质询命中点亮一格。**满三格 = 实锤**，可以不押注直接结算。

这一步把「猜」变成「举证」——正好对上工坊设定里那句原文：**「不拿情绪替代证据」**。

### 结算分层，不是对错二元

| 结果 | 收益 |
|---|---|
| 锤穿（3 格） | 高 |
| 押中但没锤穿 | 中 |
| 押错 | 低——但**破绽照样进资讯库** |

最后一条别省：输了也有东西带走，这是"玩过的局，不白玩"的落点。

### 雇来的机器人在牌桌上的两个位置

1. **上桌演角色**——占四个座位之一，你不知道它的底
2. **坐军师位**——第五张牌**横置**在你面前（横置=支援位，是桌游的通用语言），每轮给你一张额外质询牌 + 一句提示。专长决定提示方向：雇菠萝就拆 HR 话术，雇 Codex 就查岗位真伪

### 优先级

时间不够就砍：**质询牌 + 破绽槽 > 组局选人 > 军师位 > 分层结算**。前两项是把它从"动画"变成"游戏"的分水岭，其余是加分。

## 五、生图信息

**脚本**：`C:\Users\admin\Documents\New project\generate_image_openai.ps1`

```powershell
powershell -File "C:\Users\admin\Documents\New project\generate_image_openai.ps1" `
  -Model "gpt-image-2-count" `
  -Prompt "提示词" `
  -ReferenceImage "D:\bianda-paopao\docs\shots\B2.png" `
  -Size 1536x1024 `
  -OutFile "D:\bianda-paopao\public\assets\xxx.png"
```

**必须知道的几条**：

- **`-Model "gpt-image-2-count"` 是必填**。默认的 `gpt-image-2` 和 `gpt-image-1` 都返回 503 `model_not_found`
- 服务是 `https://ai.beehears.com/v1`（**不是** cf.beehears.com）
- key 读环境变量 `BEEHEARS_API_KEY`。**能用的那把在脚本自己目录的 `.env` 里**，`~/.codex/.env` 那把会返回 Invalid token（脚本目录的优先级更高，正常情况不用管）。**任何时候不要打印 key 的任何片段**
- `-ReferenceImage` 会自动走 `/v1/images/edits` 端点（垫图）
- `-Size` 只有 `1536x1024` / `1024x1024` / `1024x1536`；还支持 `-Quality high` / `-Count N`；自带重试
- 不指定 `-OutFile` 默认输出到脚本目录 `output\imagegen\`；**已存在的文件拒绝覆盖**

**风格基准**：`docs/shots/` 里 15 帧纸雕定帧图。其中 **`B2.png`** 是四只蝶翼人围着牌桌的那张——梦蝶局所有素材都拿它当 `-ReferenceImage`，风格才连得上。

**已有成品**：`public/assets/dream-table.jpg`（牌桌背景，从 B2 垫图生成，已压到 106KB 上线）。CSS 里 `#dreamGame` 有渐变兜底层，图挂了也不塌。

**色板**：深蓝纸浪 `#0A1626 / #10253E / #16334F / #1E4468`，牛皮纸 `#C9A876`，橙丝带 `#C75B2A`，暖光 `#F5C56B`。

**这轮可能要生的**：质询牌四张牌面图标、军师位横置牌的牌框、破绽槽点亮的印记。牌背和角色剪影现在是纯 CSS 画的，够用，**别为了生图把能跑的 CSS 换掉**。
