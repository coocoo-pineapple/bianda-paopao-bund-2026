# 变大泡泡 · 伪装壳系统（前端记忆点核心）

> 这是**创意分和前端分的主要来源**，优先级高于联机。
> 半天工作量，改动集中在一个新文件 + 一个数组。

---

## 一、一句话

**一份内容，五个壳。** 同一个社区，被 Word / Excel / PPT / 桌面 / 手机五种办公场景重新裱起来——每切一次壳，评委就"啊"一次。

---

## 二、为什么这件事值钱

现在的三态（社区 / 述职报告 / 桌面）是**逃生按钮**：领导来了按一下，藏起来。

升级后的壳系统是**界面本身**：社区不是躲在 Word 后面，社区就长在 Word 里、Excel 里、PPT 里。

这个区别是决定性的：

| | 逃生按钮 | 壳即界面 |
|---|---|---|
| 用户认知 | 一个彩蛋 | 这产品的形态就是这样 |
| 演示效果 | 按一下，藏了 | 按一下，**换了个宇宙但内容还在** |
| 能装多少内容 | 一个假页面 | 每个壳装一批真功能 |
| 竞品能不能抄 | 能 | **App 形态结构上做不到** |

产品思考文档风险四里写了：三个差异点中「伪装成 Word 的敢看性」最硬，因为 Blind 和脉脉是手机 App，手机 App 没法伪装成你电脑上的 Word。**壳系统就是把这个唯一的结构性优势捅到最大。**

---

## 三、五个壳装什么

**核心约束：每个壳都不许写新内容，只许给已有模块换画框。**

### 壳 1 · Word `述职报告.docx`（已完成，不动）

社区主体。泡泡广场 + 发泡泡 + 南华（干货/学习/背单词）+ 化蝶（梦蝶局/博主机器人）+ 守藏（运营后台）。六个选项卡就是六个板块。

`.paper` 白纸 + 宋体正文 + 标尺 + 状态栏「1,240 个字」，泡泡是整页唯一会动的东西。**对比即张力，这一条已经做到了，一行不改。**

### 壳 2 · Excel `2026年度预算表.xlsx`（新，半小时）

- **拼豆网格直接就是 Excel** —— 原型里的 `.sheet` 已经是网格了，补上行号列标（A B C / 1 2 3）、公式栏、底部工作表标签就成立
- 工作表标签：`Sheet1 · 预算表` / `Sheet2 · 拼豆` / `Sheet3 · 薪资情报`
- **Sheet3 是真内容**：行业薪资情报做成 Excel 表格（公司 / 职级 / 包裹 / 来源 / 可信度）。行业八卦沉淀下来的资讯库，用 Excel 呈现比用卡片列表**更像真的**
- 选中单元格时公式栏显示内容 —— 这个细节零成本，但可信度拉满

> 妙处：**摸鱼的人真的在看 Excel，只是这张 Excel 里是隔壁厂的薪资。**

### 壳 3 · PPT `组织架构调整_说明.pptx`（新，一小时）

- 左侧幻灯片缩略图栏、中间画布、底部「第 3 页，共 12 页」+ 备注区
- **梦蝶局搬进来演播**：对局每一行 = 一页幻灯片，自动翻页就是自动播放。押注区做成"投票页"，揭底做成"总结页"（破绽标在备注区）
- **博主机器人做成提案页**：四段式（人格 DNA / 框架库 / 固定动作流程 / 禁区）天然就是四张幻灯片
- 按 F5 进「放映模式」全屏播 —— 这一下是全场最像的一刻

> 妙处：**PPT 的线性叙事结构，正好是梦蝶局需要的节奏。** 不是硬套，是真合适。

### 壳 4 · 桌面（升级现有，一小时）

现在的桌面态只有图标 + 任务栏 + 一个假对话框。升级成**三个能打开的窗口**，正好装三个已有模块：

| 桌面图标 | 打开后 | 里面装的 |
|---|---|---|
| `团建照片.jpg` | 图片查看器（缩放 / 上一张下一张 / EXIF 信息栏） | **活的泡泡水面**，裱在看图软件里还在飘。拼豆作品也在相册里 |
| `新人培训录像.mp4` | 视频播放器（进度条 / 音量 / 全屏 / 倍速） | **梦蝶局回放**。进度条能拖，拖到哪一行就跳到那一行 |
| 手机投屏窗口 | 手机镜像（状态栏 / 信号 / 电量） | **捡手机文学**，已有内容原样搬进来 |

> 妙处：**图片查看器里的"照片"是活的。** 评委会盯着看两秒才反应过来。这是全产品最强的一个瞬间。

### 壳 5 · 述职报告（已完成，改定位）

保留为**真逃生态**——不装内容，纯静态假文档。

## 四、形态与键位（08-07 修订：全屏方案）

### 形态已定：浏览器 + Fullscreen API + PWA，**不做 exe**

赛制是「AI Coding 大赛」，评分含**小红书人气评选**。让人下载 exe 才能投票 = 人气分归零。加上 Windows 拦未签名 exe、Mac 评委打不开、打包要一整天——没有任何理由做 exe。

**全屏靠 `requestFullscreen()`**，地址栏标签栏全消失，视觉上和原生应用没区别。浏览器要求必须由用户点击触发，**把这个点击做成剧情**：

```
第一屏：Word 启动画面
       「正在打开 2026年度第三季度工作述职报告.docx」
        进度条 +「打开」按钮
   ↓ 点击
   进全屏 → Word 壳
```

用户以为在打开文档，其实是在授权全屏。**浏览器的限制反过来成了叙事的一部分。**

再加 `public/manifest.json`（~20 行），Chrome 会提示「安装应用」——装完独立窗口、任务栏图标、无地址栏，**exe 的观感白拿，成本 20 分钟**。

### 键位：Esc 必须让出来

**全屏下 `Esc` 被浏览器占用**（退出全屏），抢不到。而且 Esc 退出全屏 = 露出浏览器 = 暴露这是个网站，与逃生目的正好相反。

| 键 | 行为 | 定位 |
|---|---|---|
| **`` ` ``**（反引号） | 循环 Word → Excel → PPT → 桌面 → Word | **玩法**。Esc 正下方，单键，无人占用 |
| **`Ctrl+空格`** | 任何状态 → 秒切静态述职报告，再按一下回来 | **逃生**。真·老板键 |
| `Esc` | **完全不绑定** | 留给浏览器退出全屏 |

逃生要求：**150ms 内完成，不许有动画，切回来时水面状态不丢。**（`step()` 在遮罩时已暂停，`maskOn` 逻辑现成的）

界面上要有提示条：`` ` `` 切换视图 · `Ctrl+空格` 老板键

## 五、怎么实现（改动面锁死）

### 现状

```js
let maskState = 0, maskOn = false;
const MASKS = [null, '#reportMask', '#desktopMask'];
function cycleMask(){ … }
```

已经是数组驱动了，**扩展它就行，不用重构**。

### 改法

新增 `public/shells.js` 一个文件：

```js
const SHELLS = [
  { id:'word',  chrome:'#chromeWord',  title:'2026年度第三季度工作述职报告.docx - Word' },
  { id:'excel', chrome:'#chromeExcel', title:'2026年度预算表.xlsx - Excel' },
  { id:'ppt',   chrome:'#chromePPT',   title:'组织架构调整_说明.pptx - PowerPoint' },
  { id:'desk',  chrome:'#chromeDesk',  title:null }
];
function wearShell(i){ /* 换 chrome、搬 DOM 节点、改 title */ }
```

**关键实现决策：模块 DOM 节点是搬家，不是重建。**

拼豆网格、梦蝶局、捡手机文学的 DOM 只创建一次，换壳时用 `appendChild` 搬到新壳的容器里。这样：

- 所有已有事件监听、定时器、内部状态**全部自动保留**
- 不用改任何模块的初始化逻辑
- 换壳零延迟

改动清单（就这些，不许扩散）：

| 文件 | 改什么 | 量 |
|---|---|---|
| `public/shells.js` | 新增：壳定义 + `wearShell` + 键盘绑定 | ~120 行 |
| `public/app.html` | 新增 Excel / PPT / 桌面窗口三套 chrome 的 HTML + CSS | ~180 行 |
| `app.html` 的 `cycleMask` | 替换成调 `wearShell` | ~10 行 |

**不碰**：泡泡物理、`S` 状态、`mk/blow/burst/pop/sink/sync/go`、六个模块的内部逻辑。

## 六、视觉红线（沿用原型约束，一条不放松）

- 只用 `:root` 里已有的变量。Excel 绿、PPT 橙这类**品牌色只许出现在标题栏和标签**，正文区一律 Word 那套灰白
- **全站零 emoji**
- 除泡泡自身的径向高光外**禁用渐变**（桌面壁纸例外，已有）
- 圆角 ≤ 4px
- **换壳不许有转场动画**。硬切。真软件切窗口是不做动画的，做了就假
- 中文正文 `var(--serif)` 宋体

**判据：截一张图发给同事，他要在两秒内以为你在加班。** 达不到就是没做到。
