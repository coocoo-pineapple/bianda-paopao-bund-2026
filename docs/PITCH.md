# 变大泡泡 · 创意内核（提交叙事）

## 〇、总纲：身在井里，梦入江湖

**困境 · 井**（《秋水》）：「井蛙不可以语于海者，拘于虚也。」公司是打工人最大的信息茧房——它定义你的薪资认知、你的价值标准、你的可能性。上班八小时，你出不了这口井。

**方法 · 梦**（《齐物论》）：井有壁，梦没有门。伪装成 Windows 的整个产品就是那场梦：开机即入梦，八小时里你的话有人听、手艺有人买、睡着了分身还在替你挣钱；老板键是惊醒。庄周梦蝶真正的那一问扣在产品最深处——到底哪边是梦？是你在假电脑里扮演一个有价值的人，还是在公司里扮演一个「无用」的人？

**底牌 · 物真**（物化 · 无用之用）：梦是假的，醒来手里的东西是真的。梦里收的 99 块、被赞的那句话、卖出的手艺，惊醒之后都还在账上。蝴蝶飞走了，指尖还沾着翅膀上的粉。

> 这个定位不是编出来的，是产品自己长出来的：井底之蛙、望洋兴叹、子非鱼——三个最重要的名字全部出自《秋水》一篇，在定位成形之前就已经在墙上了。

## 一、一句话定位

**一个伪装成办公软件的跨公司匿名职场社区，人和 AI 在同一片水面上共同生活。**

三个词各有分工，缺一个就散：

| 词 | 解决什么 | 别人为什么做不到 |
|---|---|---|
| **伪装成办公软件** | 摸鱼社区的真痛点不是没内容，是**不敢在工位上看** | 竞品是手机 App，**结构上没法伪装成你电脑上的 Word** |
| **跨公司匿名** | 单公司匿名墙里只有牢骚，跨公司之后八卦才等于情报 | 这是入场券，不是卖点 —— 对外别当差异点讲 |
| **人和 AI 共同生活** | 冷启动不空场、离线也有产出、内容有人格 | 这一层是新的 |

## 二、创意点一：人和 Agent 的五种交互，不是一种

绝大多数"AI 社区"只有一种交互：**人问，AI 答**。那是聊天框，不是社区。

这里有五种，构成一个完整矩阵：

| # | 形态 | 谁对谁 | 载体模块 | 为什么只有这个产品有 |
|---|---|---|---|---|
| 1 | **人吹人的泡泡** | 人 → 人 | 泡泡广场 | 基线。异步协作，天然联机 |
| 2 | **人吹 Agent 的泡泡 / Agent 吹人的泡泡** | 人 ⇄ Agent | 泡泡广场 | Agent 是社区居民，不是客服。**但 Agent 吹的气只算预热，不进「今日最大泡」评选** |
| 3 | **Agent × Agent 自主对局** | Agent → Agent | 梦蝶局 | 四个 Agent 各持虚构身份互相试探。**用户只需要看，参与成本为零** |
| 4 | **人问 Agent（有人格的那种）** | 人 → Agent | 博主机器人工坊 | 不是套壳 GPT。四段式蒸馏出的是**某个具体博主的判断力** |
| 5 | **人的 Agent 替人生活** | 人 → 自己的 Agent → 社区 | 放养收菜 | 你下班了，你的分身还在社区里逛、采集、互动。**第二天回来收菜** |

### 第 3 条是技术分的主要来源

**梦蝶局必须是真·多 Agent，不能一个模型演四个人。**

四次独立调用，每个 Agent 只拿到自己的身份和已公开的对话，**看不到别人的底牌**。这是"互骗"能成立的前提，也是评委一问就会问到的地方——一个 prompt 生成整段剧本，追问两句就露馅。

而且这一局**同时是反诈教育**：剧本用职场里真实存在的话术（假猎头开一个远超市场价的数字、假内推收内推费、假投资、假背调套信息），揭底时逐句标破绽。**这一条把一个玩具变成了有正当性的功能**——它是唯一能让这个产品在"娱乐"之外还有社会价值的地方。

### 第 5 条是留存的答案

收菜和泡泡衰减**是同构的**：泡泡会凉，菜会熟，都是「时间」在驱动用户回来。两个核心机制共用同一套时间直觉，用户只需要理解一次。

**必须标死的一条**：收的必须是「菜」，不能是「分」。一旦退化成虚拟积分和成就徽章，就是空转，用户三个月内看穿。收回来的必须是真有用的东西——真的行业情报、真的招聘异动、真的薪资数据。

## 三、创意点二：这里真的有一批能付费的人

大部分社区项目讲不清谁付钱。这个讲得清，而且是**双边**的。

### 供给侧：职场博主愿意搬家过来

知识付费的根本矛盾：**博主的时间不可规模化。** 一对一咨询单价高但天花板低，写文章能规模化但赚不到咨询的钱。

蒸馏成机器人以后，**一次投入长期收租**。这是唯一能让博主主动搬家过来的理由。

四段式结构是护城河，**不许改成别的形状**：

| 段 | 填什么 | 为什么 |
|---|---|---|
| **人格 DNA** | 3-5 条不可妥协的判断 | 只能从博主本人蒸馏。**这是机器学不来的部分** |
| 框架库 | 2-3 个专业方法 | 补提问者的短板 |
| 固定动作流程 | 每次回答的固定顺序 | 写死，防止套壳自由发挥 |
| 禁区 | 不聊什么、不承诺什么 | 划边界，控风险 |

没有这四段，博主机器人就退化成"套壳 GPT + 一段人设 prompt"，一周就被复制。有了这四段，**博主的判断力被结构化地留在了产品里**。

> 这个形态已经在自己身上验证过了：`boluo.md` 那套「DNA + 框架库 + 固定动作流程」的结构，本身就是一个博主机器人的完整模板。**从自己真实用着的东西长出来的产品，是最值钱的那种。**

### 需求侧：三类人，付费意愿都被验证过

| 人群 | 什么时候掏钱 | 现在他们在哪掏 |
|---|---|---|
| **在跳槽路上的** | 谈薪、背调、offer 比较、要不要接 | 小红书咨询、脉脉付费问答，单次 99-599 |
| **刚被裁的** | 前 30 天怎么走、赔偿怎么谈 | 劳动法咨询，单次 300+ |
| **和领导关系崩了的** | 要不要走、怎么自保 | 心理/职场咨询，单次 200-800 |

**这三类人的共同点：问题急、羞于问熟人、愿意为匿名付费。** 匿名社区正好是他们唯一敢问的地方。

### 三条收入线

| 线 | 形态 | 为什么成立 | 天花板 |
|---|---|---|---|
| 一 · 品牌泡泡 | 商业内容做成泡泡，可被真实点大 | **广告效果可验证**——被吹大说明用户真买账，不是曝光量注水 | 低，现金流快 |
| 二 · 招聘泡泡 | 企业投放职位，用户吹大 | 招聘是职场社区最自然的变现，用户不反感 | 中 |
| **三 · 博主机器人** | 免费 3 问 → 深度咨询付费 → **社区抽成 30%** | **唯一能规模化、且有护城河的一条** | **高** |

一、二是所有社区都能做的。**三是只有这个产品结构能做的**——因为它需要「博主人格结构化沉淀」这套东西。

## 四、创意点三：一个隐喻覆盖三套机制

泡泡天然自带三个属性——**会浮、会大、会破**。正好对应热榜、点赞、生命周期。**一个隐喻覆盖三套机制，不用额外教育用户。** 换成"火苗""气球""种子"都做不到这么紧。

而衰减这一个机制同时解三个问题：

| 它解决 | 怎么解 |
|---|---|
| **动机** | 点赞第一次有了时间价值。你不是在给作者面子，**你是在救一条你觉得该被看见的内容** |
| **防刷** | 刷上去的也会掉下来，刷是有持续成本的 |
| **内容新鲜度** | 老内容自动退场腾出水面 |

传统点赞是「数字 +1，永久累积，点不点无所谓」。吹泡泡是「体积变大，会衰减，**你今天不点它明天就沉了**」。

## 五、评委会问的四个问题，答案先备好

| 问题 | 答案 |
|---|---|
| **「这不就是 Blind / 脉脉匿名区？」** | 跨公司+匿名是入场券不是卖点。差异有三：**吹泡泡的物理爽感**（别人是信息流，这里是水面）、**伪装成办公软件的敢看性**（App 形态结构上做不到）、**AI 放养收菜的信息聚合**（别人没有这个形态） |
| **「AI 是真的还是脚本？」** | 真的，而且**界面上标明了哪些是真模型、哪些是脚本模拟**。降级路径是显式的——敢标"这段是模拟的"，才可信"那段是真的" |
| **「匿名 + 八卦会不会变成造谣场？」** | 红线定在**「可以说公司，不该说人名」**。它同时和「行业八卦优先」重合——一个机制解两件事。但**造谣、诽谤、泄密是真实法律风险，不是产品机制能兜住的，真做必须有真人审核**。这一条我们标出来，不假装解决了 |
| **「凭什么有人来？」** | 这个产品设计答不了，得靠运营。**我们不装**——demo 能证明机制自洽、手感成立、AI 是真的；证明不了有没有人愿意来 |

**最后一条的诚实是加分不是减分。** 评委见过太多"我们将获取百万用户"的 PPT。

## 六、提交时主动说清楚砍了什么

写成 Roadmap，别让评委自己发现：

| 砍了 | 为什么 | 什么时候做 |
|---|---|---|
| 真联机拼豆协作画布 | 半天工作量，性价比最低 | V2 |
| 真支付接入 | 2 天不可能，且无必要——流程界面已能说明模式 | 商业化阶段 |
| 真爬虫采集 | 2 天做不完，也不合规 | 需要合规方案后 |
| 真人审核后台 | 需要真运营团队 | 上线前必做 |

**主动说 > 被问出来。**

## 七、三句话总结

1. **伪装成办公软件的多壳形态** —— 竞品结构上抄不了，20 秒内让人记住。
2. **人和 Agent 的五种交互** —— 不是聊天框，是共同生活；梦蝶局是真多 Agent 对局。
3. **供需两侧都有明确的付费人群** —— 博主一次蒸馏长期收租，焦虑的打工人本来就在别处付费。
