## 0.5 泡泡分级体系（你的新想法 · 提案待你批）

方向已定：**更像 Windows 气泡屏保 + 泡泡分等级/颜色/行业/分类**。我的落法提案，四个维度各占一个视觉通道，互不打架：

| 维度 | 视觉通道 | 提案 |
|---|---|---|
| **等级**（热度段位） | 大小 + 膜的亮度 | L1 新生（小、膜几乎透明）→ L2 升温（膜显彩虹）→ L3 热议（膜流转加快、高光变大）→ L4 濒爆（红脉冲，已有）。**进过名人堂又被捞回的挂金环 = 传奇泡** |
| **分类**（薪资/八卦/招聘/乐子…） | 玻璃膜的主色相 | 薪资=金膜 · 领导八卦=红膜 · 裁员=灰蓝膜 · 招聘=绿膜 · 乐子=紫膜。TYPES 色板已有，映射到 conic 渐变的主色即可 |
| **行业**（互联网/金融/制造…） | 泡顶小色徽 | 泡泡上缘一颗 6px 色点，hover 放大显示行业名。不占膜色通道 |
| **屏保感** | 运动质感 | 漂浮更慢更匀、碰撞时轻微形变（squash 0.95）、高光缓慢游移（已有）、偶发一颗慢速穿屏的"远景泡" |
